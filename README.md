Repositório dedicado ao registro dos meus **estudos e exercícios em Java**, acompanhando a prática de lógica de programação e o desenvolvimento de programas nessa linguagem.

## Objetivo

Consolidar conceitos fundamentais da programação por meio de atividades práticas, com foco na compreensão do código, na resolução de problemas e na evolução gradual dos conhecimentos em Java.

## Conteúdo do repositório

Os arquivos-fonte disponíveis neste repositório são o material principal de estudo. Para conhecer os exemplos existentes, consulte a [lista de arquivos do projeto](https://github.com/adolfo-araujo/Java-).

> Os exercícios podem ter estruturas e formas de execução diferentes; este README apresenta orientações gerais e não pressupõe um único programa principal.

## Tecnologias e conceitos

- **Java**, para implementação dos exercícios.
- **JDK (Java Development Kit)**, para compilação e execução.
- Lógica de programação e organização de algoritmos.
- Leitura, interpretação e manutenção de código-fonte.

## Como executar

1. Instale um JDK compatível com o exercício que deseja executar.
2. Clone o repositório:

   ```bash
   git clone https://github.com/adolfo-araujo/Java-.git
   cd Java-
   ```

3. Navegue até o arquivo que contém a classe principal do exercício (método `main`).
4. Para um exemplo simples, **sem declaração de `package` e sem dependências externas**, compile e execute, substituindo os nomes pelos do arquivo real:

   ```bash
   javac NomeDaClasse.java
   java NomeDaClasse
   ```

Se o exercício usar pacotes Java, bibliotecas ou um sistema de build, siga a estrutura e os comandos específicos desse projeto.

## Organização e evolução

A proposta deste repositório é preservar o histórico de aprendizagem, permitindo comparar os exercícios iniciais com projetos mais completos desenvolvidos posteriormente.
